# CaptionForge

A local desktop application for generating, editing, and burning subtitles into videos.

## Prerequisites

- Python 3.10+
- FFmpeg installed on your system:
  ```bash
  # Linux (Ubuntu/Debian)
  sudo apt update
  sudo apt install ffmpeg
  ```

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

```bash
python main.py
```
